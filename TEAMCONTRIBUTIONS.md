## Preparing a member attribution

Before each member's work session, set the repository-local Git identity:

```powershell
git config user.name "Full Member Name"
git config user.email "member-github-noreply@example.com"
```

Use the member's verified GitHub noreply email from GitHub account settings.
Do not use another person's GitHub account or a shared password. Commit from
the branch used for the group repository:

```powershell
git add -A
git commit -m "Describe the work"
git push origin main
```

The member should sign in to GitHub if prompted. Existing history is not
rewritten; new commits appear in each member's contributor activity when the
commit email is linked to that member's GitHub account.
